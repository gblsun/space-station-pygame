As figuras em [img/](img/) são geradas pelo próprio motor gráfico — a planta do
referencial da estação, a folha de contato das quatro fases e o Sistema Solar na posição
do dia em que o script roda:

```bash
python docs/gerar_figuras.py
```

Regere-as depois de qualquer mudança na cena, para que o material de apoio não divirja
do que a aplicação desenha.

> **Pendências para a equipe:** os trechos marcados com **[CONFIRMAR]** em
> [03-decisoes-tecnicas.md](03-decisoes-tecnicas.md) descrevem fatos sobre o trabalho de
> vocês — dificuldades encontradas e divisão de tarefas — e precisam ser revistos antes
> da entrega.
